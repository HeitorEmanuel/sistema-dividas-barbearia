# Sistema de Controle de Dívidas para Barbearia

Sistema web desenvolvido com Python e Django para gerenciamento de clientes e controle de dívidas em barbearias.

## Funcionalidades

* Cadastro de clientes
* Controle de dívidas
* Pagamento individual ou em lote
* Histórico de ações
* Relatórios PDF por período
* Controle de usuários
* Troca de senha
* Backup do sistema
* Pesquisa por nome e telefone
* Interface responsiva

## Tecnologias

* Python
* Django
* Bootstrap
* SQLite
* ReportLab

## Objetivo

O projeto foi desenvolvido para solucionar um problema real de gestão de fiados em uma barbearia, permitindo um controle simples, rápido e seguro das dívidas dos clientes.
